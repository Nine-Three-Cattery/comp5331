# Independent deterministic design and legacy separation

The registered K1 branch is `causal/`, written independently in PyTorch. Each observation-complete actor has recurrent hidden/cell states. A recipient-centered grid sums previous neighbor hidden vectors, excludes self/padding, and isolates batch examples. Eight observed positions, absolute metric origins and history-derived displacements initialize states. All actors then roll forward jointly for twelve steps without teacher forcing; only target future positions supervise closed-loop MSE.

The input origin is the target's final visible/causally filled position. A fixed anchor is the average of its last three observed displacements (and similarly for each neighbor); a deterministic learned residual adjusts each future displacement. This avoids the legacy sampled-velocity identity feedback. Output is directly returned to metric coordinates. Hidden64/embedding32/grid4x4/4m square, Adam.001, weight decay.0001, clipping10 and batch32 are frozen before the pilot. Formal default12 epochs; clean validation meanADE selects the checkpoint, earlier epoch for ties. Config records identities, source hashes and environment.

The owner feature builder reads shared neutral positions only, ignoring stored derivative columns. It retains all actors with eight observed points, then admits those within6m at any observed time relative to the perturbed target. Only target history receives the shared perturbation. Neighbor future availability and all future coordinates are excluded from inputs. Original manifest indices determine corruption seeds even when batches are shuffled or bucketed. Labels are read separately. The same observation-derived context is rolled forward in training and prediction.

Actor-count buckets of256 are shuffled within and across minibatches with seeded RNG; each training manifest index occurs once per epoch. Test output order remains exactly the shared manifest order. There is no learned normalization or map input. The common neutral bundle/evaluator is reused, not a third-party neural network.

This is a deterministic adaptation of the paper's social mechanism; its Gaussian head, original hidden/grid sizes and optimization are not reproduced. Model quality must be assessed from actual shared pilot/formal outputs, not merely unit tests. The runtime host/software can differ from the reference environment only when explicitly disclosed and presented separately.

The preserved `legacy/` branch remains probabilistic K20 with old seeds/splits/corruption and a sampled-velocity residual mean. Its engineering checks and numerical results cannot establish the new branch's quality, and its arrays are not shared bundles. Typical-sample legacy error was worse than CV. A one-fold anchored legacy control also worsened validation error/energy; that is not evidence that the new K1 design is a proven fix. New results must stand on their own.
